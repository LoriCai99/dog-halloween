# 狗狗万圣变装间 🎃🐶

给办公室的两只狗狗做万圣节数字变装的小网页。

- 88 件手绘装扮（帽子头饰、脸部、服装道具、场景装饰），外加文字、表情贴纸、相框和滤镜
- 拖动、缩放、旋转、翻转、调整图层，手机上可以双指操作
- 🎲 一键随机变装
- 可以上传自己的照片，保存成 PNG 发到群里

纯前端，一个 HTML 文件，不需要服务器。

## 文件

| 文件 | 用途 |
| --- | --- |
| `dog-costume.html` | 源文件（也是 Claude Artifact 版本，带共享展览墙） |
| `index.html` | 由 `./build.sh` 生成，给 GitHub Pages 等静态托管用 |

修改 `dog-costume.html` 后运行 `./build.sh` 重新生成 `index.html`。

## 两个版本的区别

- **Claude Artifact 版**：有共享的展览墙，可以发布作品、点赞排名，编辑者可以上传办公室狗狗的照片。
- **静态网页版**（GitHub Pages）：任何人打开就能玩，但没有展览墙，大家保存图片后发到群里分享。
  办公室狗狗的照片可以通过「用我的照片」上传。
