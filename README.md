# 毛孩子万圣变装间 🎃🐶🐱

上传你家毛孩子的照片，做万圣节数字变装的小网页：<https://loricai99.github.io/dog-halloween/>

- 132 件手绘装扮（帽子头饰、脸部、服装道具、侧脸侧身、场景装饰），侧脸、侧身、趴着的毛孩子也能穿
- 选中装扮可以「变窄 / 变宽」，正面装扮压窄再转一点就能贴合斜角的脸
- 41 句猫狗中英文文字贴纸，也能自己写
- 28 个表情贴纸、6 种相框、7 种滤镜，还有贴纸白边和纸感颗粒
- 拖动、缩放、旋转、翻转、调整图层，手机上可以双指操作；🎲 一键随机变装
- 打开就是上传框：点一下或把照片拖进去，图片只留在自己的浏览器里，不会上传
- 竖屏 / 横屏 / 方形等画面比例，可拖动、缩放照片
- 保存成 PNG 发到群里

纯前端，不需要服务器。

## 文件

| 文件 | 用途 |
| --- | --- |
| `dog-costume.html` | 源文件（也是 Claude Artifact 版本，带共享展览墙） |
| `index.html` | 由 `./build.sh` 生成，GitHub Pages 用 |

修改 `dog-costume.html` 后运行 `./build.sh` 重新生成 `index.html`。
